# PV-Waschanlage Website

Eine exakte Kopie der Website https://www.pv-waschanlage.de/

## Beschreibung

Diese Website bewirbt die mobile PV-Waschanlage von Hermann Popko GmbH für die professionelle Reinigung von Photovoltaikanlagen.

### Hauptfeatures:
- Bis zu 30% Leistungssteigerung
- Maximale Lebensdauer der Module
- 20% Kostenrückerstattung gemäß §35a Abs. 3 EStG

### Technologie:
- Responsive Design
- Bootstrap-basiert
- Moderne CSS & JavaScript
- Bildergalerie
- Kontaktformular
- FAQ-Bereich

## Struktur

- `index.html` - Hauptseite
- `css/` - Stylesheets
- `javascript/` - Scripts
- `img/` - Icons und SVGs
- `assets/` - Bilder und Medien
- `_resources/` - Zusätzliche Vendor-Ressourcen

## Nutzung

Öffne einfach `index.html` in einem Browser.
